# Closing: Primary Question Plus a Prespecified Safety or Secondary Question

`Use when the study was designed to answer two prespecified questions, typically efficacy plus a safety concern raised by the gap paragraph (or a pooled effect plus prespecified heterogeneity in a meta-analysis).`

## Skeleton

```
% State the primary aim
We conducted a [DESIGN] to assess whether [INTERVENTION] reduces [PRIMARY OUTCOME] in [POPULATION].

% State the concern that justifies the second question
Because [INTERVENTION] could plausibly [HARM / TRADE-OFF], which prior studies were not powered to detect,

% State the second prespecified question and how it was handled
we prespecified [SAFETY OUTCOME] as a [co-primary / key secondary] outcome, assessed for
[noninferiority with margin X / superiority].
```

## Worked example (illustrative; fictional)

```
We conducted a multicentre randomized trial to assess whether a restrictive,
physiology-guided fluid strategy reduces 90-day mortality compared with usual care in
adults presenting to the emergency department with septic shock. In the restrictive
arm, additional fluid was given only when passive leg raising indicated fluid
responsiveness. Because restricting fluid could plausibly increase acute kidney
injury, which earlier trials were not powered to detect, we prespecified acute kidney
injury within 7 days as a co-primary safety outcome with a noninferiority margin.
```

## Notes and pitfalls

1. The second question must be motivated in the gap paragraph, not introduced for the first time here.
2. Two primary or co-primary outcomes require a multiplicity strategy; state it in the Methods and keep the Introduction consistent with it.
3. Do not present a post-hoc secondary analysis as a second aim. Only prespecified questions belong in the closing paragraph.
