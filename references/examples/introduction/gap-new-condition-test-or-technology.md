# Gap: A New Condition, Test, or Technology Has Not Been Evaluated

`Use when the question is new because the entity itself is new: a recently recognized syndrome, a new diagnostic test or device, a new drug class, or a recent change in regulation or practice. Prior evidence is indirect by definition.`

## Skeleton

```
% Introduce the new entity and why it matters now
[ENTITY] was [recognized / approved / introduced] in [YEAR] and is now [used in / affecting] [POPULATION].

% State what is known and what is not
Early reports describe [WHAT IS KNOWN], but [KEY UNKNOWN: frequency / accuracy / long-term
outcome / harms] has not been measured in [POPULATION].

% Name the specific obstacles a credible study must overcome (at most three)
Answering this requires [REQUIREMENT 1: a consensus definition / a reference standard],
[REQUIREMENT 2: an appropriate comparator], and [REQUIREMENT 3: complete follow-up].
```

## Worked example (illustrative; fictional)

```
Post-intensive-care cardiopulmonary impairment after severe COVID-19 was recognized
during 2020 to 2022, and many survivors are now followed in outpatient clinics. Early
case series describe reduced exercise capacity and abnormal lung imaging, but the
frequency of persistent impairment 3 years after discharge has not been measured in a
defined cohort. Three features of the condition make this difficult. First, there is no
consensus operational definition, and symptom-based, imaging-based, and exercise-based
criteria identify different patients. Second, because infection was widespread, a
contemporaneous uninfected comparator group is rare, and historical controls differ in
baseline cardiopulmonary status. Finally, attrition among intensive-care survivors is
high and plausibly related to the outcome itself.
```

## Notes and pitfalls

1. Use this pattern only when the entity is genuinely new. Applied to an established question, it reads as inflating novelty.
2. Each obstacle you name should be answered by a specific choice in the Methods (the definition adopted, the comparator used, how attrition was handled). If the Methods do not address it, do not list it.
3. Frame obstacles as properties of the clinical question, not as difficulties of "our task" or "our approach".
