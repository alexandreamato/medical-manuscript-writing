# Discussion: Possible Mechanisms, Hedged

`Use when a mechanism helps readers judge plausibility. State it as a hypothesis, support it with evidence, and say what this study did not measure.`

Worked examples use the same fictional trial as the Results examples (supervised exercise plus compression vs compression alone in venous leg ulcer; healing 62.0% vs 51.0% at 24 weeks), and one fictional cohort study (statin use and incident venous leg ulcer, adjusted hazard ratio 0.72, 95% CI 0.55 to 0.94) to show observational wording.

## Skeleton

```
% The candidate mechanism, clearly a hypothesis
A possible explanation is [MECHANISM], because [EVIDENCE from other studies] [ref].

% What this study measured, or did not
We did not measure [MEDIATOR], so this explanation remains untested in our data.
```

## Worked example (illustrative; fictional; citation is a placeholder)

```
A possible explanation is improved calf-muscle pump function, which reduces venous
hypertension at the ulcer site; supervised exercise has been reported to increase
ejection fraction of the calf pump in patients with venous disease [CITATION NEEDED].
We did not measure calf-pump function, so this mechanism remains a hypothesis in our
trial.
```

## Notes and pitfalls

1. Hedge in proportion to the evidence: "may", "a possible explanation", "is consistent with".
2. One or two mechanisms, briefly. A long physiology review distracts from the finding.
3. Never present a mechanism as demonstrated when the study did not test it.
