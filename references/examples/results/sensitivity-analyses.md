# Results: Sensitivity Analyses

`Use to show whether the primary result depends on an analytic choice: missing data, analysis population, model, or definition of the outcome.`

All worked examples in this folder use one fictional randomized trial: 600 adults with venous leg ulcer randomized to supervised exercise plus compression (n = 300) or compression alone (n = 300); primary outcome complete healing at 24 weeks.

## Skeleton

```
% What was varied, and the result in each
The result was similar in [ANALYSIS 1] ([estimate, CI]) and [ANALYSIS 2] ([estimate, CI])
([Supplementary Table n]).

% Missing-data robustness
[Tipping-point / worst-case] analysis: the conclusion would change only if [CONDITION].
```

## Worked example (illustrative; fictional)

```
The result was similar in the per-protocol population (absolute difference 12.4
percentage points, 95% CI 4.0 to 20.8) and in the complete-case analysis (11.3
percentage points, 95% CI 3.2 to 19.4) (Supplementary Table 4). In a tipping-point
analysis, the difference would lose statistical significance only if patients lost to
follow-up in the exercise group had healed at less than a third of the rate observed in
those who completed follow-up.
```

## Notes and pitfalls

1. Report sensitivity analyses that were planned, and label added ones as post hoc.
2. When a sensitivity analysis changes the conclusion, say so in the Results and discuss it; do not move it to the supplement to hide it.
3. The primary analysis stays primary even when a sensitivity analysis looks better.
